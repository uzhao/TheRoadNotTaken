## 输出格式

你的**最终回复就是讲义本身**：一份 markdown，不要任何前言、后记或对本任务的说明。结构如下：

1. `# ${topic_name}`（第一行，一级标题）
2. `## 历史动机`：200–400 字，这个主题的概念为了解决什么问题、在怎样的历史背景下出现。
3. 每个概念一节 `## <概念>`，按提纲顺序；讲清定义、直观与关键结论。
4. `## 例题`：2 道例题，给出完整的解题过程。
5. `## 常见误区`：可选。
6. `## 小结`：3–5 条要点。

全文 1500–3000 字。公式用 `$$…$$`（行内）与 `$$$$…$$$$`（独立成行）的 LaTeX 写法，不要写 HTML。

## 插图

插图可选，整份讲义 0–4 张，只在图能明显帮助理解时才画。每张图：

- 用 Python + matplotlib 画：先把脚本写到 `figures/<名>.py`，再在当前目录执行 `python3 figures/<名>.py`，脚本把图存到 `figures/<名>.svg`；只有 3D 曲面、密集散点、热力图这类 SVG 会很大的图才存 `figures/<名>.png`。不要动画。
- `<名>` 是语义化的英文 slug（小写字母、数字、连字符），例如 `secant-to-tangent`。
- 当前目录已有统一的 `matplotlibrc`（中文字体、SVG 文字、画布与分辨率），直接使用，不要在脚本里改字体、不要用 TeX。
- 在讲义里用 `![图注](figures/<名>.svg)` 引用；图注是一句能独立成立的中文，兼作替代文字。只用这种写法与相对路径。
- 图中标签优先用数学记号（mathtext 的 `$$…$$`），坐标轴要有标签；白底、浅色，不考虑深色模式。
- 每张图不超过 500 KB。脚本执行成功、文件存在即可，不必再查看图片。

