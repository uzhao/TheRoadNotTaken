## Question

每类 agy 调用的输入、输出与会话归属是什么？需要定下：

- **讲义生成**：prompt 里给哪些内容（主题定义、概念提纲、前置主题名、薄弱点、插图契约、提议规则、历史动机索引）；输出是 markdown 还是 `--json-schema` 包装；历史动机、正文、例题各自的篇幅与顺序要求。
- **追问**：续接主题会话时附带什么上下文（当前讲义是否需要重发）；回答的长度与插图约束。
- **验证出题**：独立会话（005 已定），`--json-schema` 的题目结构；2–3 题如何覆盖概念提纲与薄弱点。
- **评分**：输入学习者作答与参考答案；输出每题分数、评语、薄弱点列表、是否通过的阈值；是否与出题同一会话。
- **申诉**：学习者一次申诉的输入形式；是否续接评分会话；申诉成功后的状态变化。
- **薄弱点回流**：薄弱点如何进入下一次讲义生成与追问的 prompt；验证通过后清空（005 已定）之外是否有部分清除。
- **模型选择**：以上各类调用分别用哪个模型与 effort（见 [agy print 模式实测](./002-agy-print-mode.md) 的模型清单与延迟数据）。
