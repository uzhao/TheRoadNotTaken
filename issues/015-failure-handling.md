## Question

[agy print 模式实测](./002-agy-print-mode.md) 给出了失败形态：exit 3 加 `AGY_ERROR`（含 `retryable`，如 429 配额）、硬超时、`SUCCESS` 但无 `structured_output`、权限被拒的 `denied_actions`、搬运校验失败。针对讲义生成、追问、验证出题、评分、申诉、提议起草各流程，需要定下：

- 哪些失败自动重试、重试几次、是否换模型（如 Claude 配额耗尽时退到 Gemini）；哪些直接报错。
- 失败时界面显示什么、学习者能做什么（重试、换模型、放弃）；状态是否回滚（如评分失败时验证记录如何写）。
- 超时后已流出的部分讲义正文是否保留给学习者看。
- agy 不可用（未登录、网络断）时应用的启动行为与降级：缓存讲义可读、验证不可做。
- 任务目录与 `agy.ndjson` 的保留期限与清理。

## Resolution

经一轮 grilling 定下（无需 ADR）：

1. **自动重试矩阵**：
   - `AGY_ERROR` 且 `retryable: true`（429、5xx、网络）：10 秒后同模型自动重试一次，再失败报错；
   - `AGY_ERROR` 不可重试（未登录、参数错）：不重试；
   - 硬超时：不自动重试，报错并保留部分正文；
   - `SUCCESS` 但无 `structured_output`（出题、申诉、起草）：同一会话追加"请只通过结构化结果提交"重试一次，再失败报错；
   - 出现 `denied_actions`：配置错误，不重试，报"agy 权限未放行"并指向 [agy 权限规则配置实测](./011-agy-permission-rules.md)；
   - 搬运校验失败：按 005 同会话重试一次。
   - **不自动切换模型**；错误面板提供"换个模型重试"的一次性覆盖（下拉列出 002 的模型清单）。
2. **失败不写任何状态**：讲义生成失败 → 主题仍 `learning`、无讲义，卡片标"生成失败"并可重试，任务目录保留；追问失败 → 该条消息显示错误与重试，不记录；出题失败 → 不写验证记录、状态不变；申诉失败 → 不消耗申诉次数；起草失败 → 提议保持 `pending`。错误面板显示 `short_error` 与 `error_id`，附"复制诊断信息"（任务 id、命令行、最后 20 行 `agy.ndjson`）。
3. **超时的部分正文**：已流出的讲义正文留在页面，顶部横幅"生成超时，以下为部分内容，未缓存"并提供重试；不写入 `lectures/`。追问超时同理，不记入 `followups.jsonl`。
4. **agy 不可用**：启动不做健康检查；第一次调用失败即在顶栏显示全局横幅"agent 不可用：<short_error>"（配额类附重置时间），缓存讲义照常可读，追问、验证、重生成置灰并说明原因，横幅提供"重试连接"（一次最小调用）。
5. **保留与清理**：成功任务目录搬运后立即删除；失败的保留，启动时清理 7 天前的且最多保留最近 20 个；`agy.ndjson` 随目录；后端日志按天滚动保留 14 天。
6. **排队与取消**：并发上限 2，其余排队并显示"排队中（第 n 位）"；排队中与运行中的任务均可取消（杀进程组、删任务目录、不改状态）；后端重启时未完成任务视为失败，刷新后显示"上次生成被中断"与重试。
