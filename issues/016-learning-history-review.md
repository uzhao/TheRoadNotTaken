## Question

学习记录如何回看、已掌握的主题是否复验？需要定下：

- 回看入口：按主题查看历次验证记录、追问记录（`followups.jsonl`）、讲义重新生成历史，还是只看当前状态。
- 是否对 `mastered` 主题做间隔复验；若做，间隔规则、复验失败时状态如何变（回到 `learning` 还是新增状态）、复验在推荐中的优先级。
- 学习时间与进度统计是否进入 v1。
- 不进 v1 的部分明确划出范围。

## Resolution

经一轮 grilling 定下（无需 ADR）：

1. **回看入口**：任何主题（含已掌握）的卡片都可进学习页；右侧面板分"追问 / 历史"两个页签，"历史"列出该主题的验证记录（日期、几对几、是否通过、申诉结果；展开可看每题与作答）、追问记录（`followups.jsonl`，含验证后对话）、重新生成次数。不做独立历史页面或全局时间线。
2. **复验**：不做自动间隔复验。已掌握主题提供手动"再验一次"，流程同普通验证；通过只追加记录；未通过则退回 `learning` 并记录薄弱点，后继主题状态不变、不级联；推荐按 013 第 2 级把它排前。
3. **统计**：只保留侧栏领域进度条与顶栏"已掌握 N / 总数"；不记时长、不做连续天数、不画图表。
4. **事件日志**：不新增事件文件；"最近做了什么"由数据目录的 git 历史承担，后端提交信息写成人可读（如"验证通过：导数的定义 4/5"）；界面不展示 git log。
5. **不进 v1**（已写入地图 Out of scope）：间隔重复算法与复习排程、学习时长与打卡统计、笔记与导出、全局时间线/事件日志界面。
