## What to build

知识网页顶部显示唯一一张推荐卡：待验证优先于学习中、学习中优先于未学、主干优先于分支、与最近主题同领域优先、后继多者优先、id 兜底；卡片写明命中的理由。学习者可「我已掌握」（变为声称掌握，推荐随即变成验证）、「其实没学过」（撤回）、「暂不学」（立即换下一个）、在看板上「恢复推荐」；分支领域有「纳入推荐」开关，默认关闭。每次状态写入经 schema 校验、临时文件原子替换，并以人可读信息提交 git。

## Acceptance criteria

- [ ] 推荐算法为纯函数并通过 API 覆盖六级字典序的每一级（各一个构造状态的用例）
- [ ] `claimed` 主题推荐为验证，`deferred` 不出现直到候选耗尽，分支开关关闭时分支主题不出现
- [ ] 四个状态动作各自只改目标主题，`updated_at` 更新，`git log` 出现人可读提交
- [ ] 候选为空且无暂不学时显示规格要求的提示
- [ ] 写入过程中断不会留下损坏的 `state.json`（用临时文件 + 原子改名验证）
