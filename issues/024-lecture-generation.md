## What to build

学习者点「开始学习」后进入学习页：讲义正文逐字流式出现，顶部步骤条显示「生成正文 / 画图 xxx（第 n 次尝试）/ 讲义已缓存」，插图位置先是占位框、画好后以 `<img>` 显示；公式用 KaTeX 渲染。生成完成后讲义被校验并搬入正式位置，再次打开秒开。prompt 由后端按规格拼装（画像、主题定义、前置名、薄弱点、历史索引、插图契约、提议规则），模板带版本；每个任务目录放统一的 `matplotlibrc`；`meta.json` 记录全部元数据。底部「我学完了，去验证」（占位）与「稍后再学」。

## Acceptance criteria

- [ ] 讲义任务用假 agy 跑通：SSE 文本增量、工具步状态、完成后 `lecture.md`、`figures/`（含 `.py`）、`meta.json` 落盘并 git 提交
- [ ] 搬运校验每条规则各有失败用例，失败触发同会话一次重试（prompt 含错误与「修图或删引用」两个出口），再失败任务目录保留、主题仍为学习中
- [ ] 缓存命中时不启动 agy；讲义页顶部显示状态与薄弱点
- [ ] 插图经静态路由返回，越界路径返回 404；前端不内联 SVG、不渲染原始 HTML
- [ ] 主题从未学进入学习中并产生 git 提交；「稍后再学」回到知识网
