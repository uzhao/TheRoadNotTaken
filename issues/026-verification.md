## What to build

学习者点「去验证」或在推荐卡点「开始验证」：后端新开独立会话出 5 道单选题（schema 校验、每概念至少一题、薄弱点至少两题、不与最近两次重复、选项打乱），一页列出；提交后程序按答案键判分，至多错一题通过。通过则已掌握、薄弱点清空、后继解锁；未通过则回到学习中、薄弱点记为「概念：错选项解析」，并给「重读现有讲义 / 针对薄弱点重新生成」两个按钮。每个选项显示解析并着色。已掌握主题可「再验一次」，未通过退回学习中但不级联。

## Acceptance criteria

- [ ] 出题任务的 schema 校验覆盖：恰好 5 题、概念属于提纲、4 个互不相同选项、答案索引合法、4 条解析；不合格视为失败
- [ ] 选项顺序在展示前打乱且答案键随之映射；判分不调用 agy
- [ ] 通过与未通过的状态、薄弱点、验证记录（含每题与作答）按规格写入并 git 提交
- [ ] 声称掌握的主题验证通过后变为已掌握；「再验一次」未通过时后继主题状态不变
- [ ] 未通过结果页两个按钮分别跳转学习页（缓存）与触发重新生成任务
